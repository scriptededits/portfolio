# SCRIPTED EDITS — Video Editor Portfolio

A high-energy, neo-brutalist portfolio website built with HTML5, CSS3, JavaScript, and GSAP (featuring ScrollTrigger and buttery smooth scroll).

## ✨ Features
- **Neo-Brutalism Design**: High-contrast vibrant accents, heavy borders, bold drop shadows, sticker badges, and punchy typography.
- **GSAP & ScrollTrigger Animations**: Entrance hero timeline, scroll-triggered card pop-ins, horizontal project highlights, and infinite marquee tickers.
- **Video Editor Showcase**: Clean cards configured with Google Drive links for client reviews, showreels, and project previews.
- **Interactive UI**: Custom brutalist cursor, 3D interactive tilt cards, copy-email toast, and project filtering.
- **Fully Responsive**: Optimized for ultra-wide monitors down to mobile devices.

## 🚀 Setup & Customization
1. Open `index.html` in any browser or run with a local server (`python3 -m http.server 8000` or VS Code Live Server).
2. To swap project links, open `index.html` and replace the placeholder `https://drive.google.com/...` URLs with your actual Google Drive video links.
3. Update your bio and contact email in `index.html`.
